# house-price-prediction-ml
House Price Prediction using Machine Learning

A beginner-friendly Machine Learning project built using Python and Scikit-learn.

Skills Learned

- Linear Regression
- Training a Machine Learning model
- Making predictions
- Taking user input in Python

Technologies Used

- Python
- Scikit-learn
- Google Colab

How It Works

The model learns a simple relationship between house size and price from sample training data. It predicts an estimated price for a given house size.

Project Type

AI/ML Mini Project
